# Datenschutzerklärungen

Datenschutzerklärungen der Apps von christophs-apps, veröffentlicht über
GitHub Pages unter <https://ghostdragonseram.github.io/datenschutz/>.

Neue App: `<app>.md` anlegen (Vorlage: `minispiele.md`) und in `index.md`
verlinken. Die Seite ist dann unter `…/datenschutz/<app>` erreichbar.
